# Power-BI-projects
A collection of interactive Power BI dashboards built for business, healthcare, and public data analysis.
---
This repository contains three dashboard projects:

- Sales Dashboard
- COVID-19 Dashboard
- Diabetes Dashboard

Each project includes the Power BI report file, dataset, preview image, and a project-specific README.
